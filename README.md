# AI Fusion Chat: Hybrid RAG & Multi-Model Aggregator
AI Fusion Chat is a high-performance, full-stack AI application designed to eliminate hallucinations and provide comprehensive answers by aggregating intelligence from multiple Large Language Models (LLMs)

It features a Hybrid RAG (Retrieval-Augmented Generation) engine that dynamically selects context between a local Vector Database (private documents) and Real-Time Web Search (Tavily API), orchestrated via an asynchronous FastAPI backend
